## Curriculum Overview
**Exam Board**: Cambridge IGCSE Computer Science (0478 / 0984), 2023–2025 syllabus. Ten topic areas, split across a theory paper and a practical problem-solving/programming paper.

### 1. Data representation
- **1.1 Number systems**: Why computers use binary; denary, binary and hexadecimal; conversions between all three (max 16-bit); why hexadecimal is used; adding two 8-bit binary integers and overflow; logical binary shifts; two's complement for positive and negative 8-bit integers.
- **1.2 Text, sound and images**: Character sets (ASCII, Unicode); sound representation — sample rate and sample resolution; image representation — resolution and colour depth; effects on file size and quality.
- **1.3 Data storage and compression**: Units from bit to exbibyte (using 1024); calculating image and sound file sizes; purpose and need for compression; lossy vs. lossless methods (e.g. RLE).

### 2. Data transmission
- **2.1 Types and methods**: Packets (header, payload, trailer) and packet switching; serial/parallel and simplex/half-duplex/full-duplex; USB interface.
- **2.2 Error detection**: Why errors occur; parity check (odd/even, parity byte and block), checksum, echo check; check digits (ISBN, barcodes); automatic repeat query (ARQ).
- **2.3 Encryption**: Need for and purpose of encryption; symmetric vs. asymmetric encryption (public and private keys).

### 3. Hardware
- **3.1 Computer architecture**: Role of the CPU and microprocessor; Von Neumann architecture — ALU, CU, registers (PC, MAR, MDR, CIR, ACC), buses (address, data, control); fetch–decode–execute cycle; cores, cache and clock speed; instruction sets; embedded systems.
- **3.2 Input and output devices**: Input devices (scanners, cameras, keyboard, mouse, touch screen types, 2D/3D scanners); output devices (printers, screens, projectors, actuators, speakers, 3D printers); sensors and selecting a suitable sensor for a context.
- **3.3 Data storage**: Primary storage (RAM, ROM, differences and why both are needed); secondary storage; magnetic, optical and solid-state (flash) storage operation; virtual memory; cloud storage and its pros and cons.
- **3.4 Network hardware**: Network interface card (NIC); MAC address (structure, manufacturer + serial code); IP addresses (static/dynamic, IPv4 vs. IPv6); role of a router.

### 4. Software
- **4.1 Types of software and interrupts**: System vs. application software; role and functions of an operating system; how hardware, firmware and OS run application software; interrupts — how generated and handled (interrupt service routine), software vs. hardware interrupts.
- **4.2 Programming languages, translators and IDEs**: High-level vs. low-level languages; assembly language and assemblers; compilers vs. interpreters (translation and error reporting); advantages and disadvantages of each; role and common functions of an IDE.

### 5. The internet and its uses
- **5.1 The internet and the world wide web**: Internet vs. WWW; URLs; HTTP and HTTPS; purpose and functions of a web browser; how a web page is located, retrieved and displayed (browser, IP address, DNS, web server, HTML); cookies (session and persistent).
- **5.2 Digital currency**: Concept and use of digital currency; blockchain as a digital ledger of tamper-proof, time-stamped records.
- **5.3 Cyber security**: Threats — brute-force, data interception, DDoS, hacking, malware (virus, worm, Trojan, spyware, adware, ransomware), pharming, phishing, social engineering; protective solutions — access levels, anti-malware, authentication, automatic updates, firewalls, privacy settings, proxy servers, SSL.

### 6. Automated and emerging technologies
- **6.1 Automated systems**: Sensors, microprocessors and actuators working together; advantages and disadvantages of automated systems for given scenarios (industry, transport, agriculture, weather, gaming, lighting, science).
- **6.2 Robotics**: What robotics is; characteristics of a robot (mechanical structure, electrical components, programmable); roles, advantages and disadvantages of robots.
- **6.3 Artificial intelligence**: What AI is; main characteristics (data + rules, ability to reason, learn and adapt); expert systems (knowledge base, rule base, inference engine, interface) and machine learning.

### 7. Algorithm design and problem-solving
- **7.1**: Program development life cycle (analysis, design, coding, testing); sub-systems (input, process, output, storage); decomposition; structure diagrams, flowcharts and pseudocode; explaining the purpose of an algorithm; standard methods — linear search, bubble sort, totalling, counting, finding max/min/average; validation checks (range, length, type, presence, format, check digit) and verification checks (visual, double entry); test data (normal, abnormal, extreme, boundary); trace tables / dry runs; identifying and correcting errors; writing and amending algorithms in pseudocode, program code and flowcharts.

### 8. Programming
- **8.1 Programming concepts**: Variables and constants; data types (integer, real, char, string, Boolean); input and output; sequence, selection (IF, CASE), iteration (count-controlled, pre-condition, post-condition); totalling and counting; string handling (length, substring, upper, lower); arithmetic, logical and Boolean operators; nested statements (up to three levels); procedures, functions and parameters (up to two), local vs. global variables; library routines (MOD, DIV, ROUND, RANDOM); writing maintainable programs (meaningful identifiers, commenting).
- **8.2 Arrays**: Declaring and using 1D and 2D arrays; using variables as indexes; reading and writing array values with iteration (including nested).
- **File handling**: Purpose of storing data in a file; open, close, read and write single items and lines of text.

### 9. Databases
- **9.1**: Defining a single-table database (fields, records, validation); suitable data types (text/alphanumeric, character, Boolean, integer, real, date/time); primary keys; reading, understanding and completing SQL scripts (SELECT, FROM, WHERE, ORDER BY, SUM, COUNT).

### 10. Boolean logic
- **10.1**: Standard logic gate symbols; functions of NOT, AND, OR, NAND, NOR, XOR; building logic circuits from a problem statement, logic expression or truth table; completing truth tables; writing logic expressions (max three inputs, one output, no simplification).
